# 内容摘要技能

## 使用场景

当需要为采集到的项目生成简洁准确的中文摘要时使用此技能。

## 执行步骤

### 1. 读取项目信息

从原始数据中提取以下字段：
- 项目名称
- 项目描述
- 项目链接
- 话题标签

### 2. 分析项目内容

如果项目有 README 文件，抓取并分析：
- 项目定位
- 核心功能
- 技术特点
- 使用场景

### 3. 提取关键信息

从项目信息中提取：
- 项目做什么
- 解决什么问题
- 有什么特点
- 适合谁用

### 4. 生成摘要

遵循公式：`{项目名} + 做什么 + 为什么值得关注`

示例：
```
LangGraph 是 LangChain 的图结构 Agent 框架，支持复杂工作流编排，适合需要多步决策的 AI 应用。
```

### 5. 验证摘要

检查摘要是否符合要求：
- 中文表述
- 2-3 句话
- 简洁准确
- 不编造信息

### 6. 补充细节

如果摘要过于笼统，补充具体细节：
- 技术栈
- 主要特点
- 使用场景

### 7. 输出结果

将摘要添加到项目数据中。

## 注意事项

- 摘要必须使用中文
- 不编造数据，所有信息来自实际分析
- 摘要要简洁，避免冗长
- 突出项目的核心价值

## 输出格式

```json
{
  "summary": "一句话中文摘要"
}
```
