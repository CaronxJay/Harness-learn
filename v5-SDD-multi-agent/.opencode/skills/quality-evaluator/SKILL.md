# 质量评估技能

## 使用场景

当需要对采集到的项目进行质量评估，确定其质量等级时使用此技能。

## 执行步骤

### 1. 读取项目信息

从原始数据中提取以下字段：
- 项目名称
- 项目描述
- Stars 数量
- 话题标签
- 最近更新时间

### 2. 分析项目热度

评估项目热度指标：
- Stars 数量
- 最近更新频率
- 社区活跃度

### 3. 评估技术创新

分析项目的技术特点：
- 是否解决新问题
- 是否有创新方法
- 是否有技术突破

### 4. 确定质量等级

根据评估结果，确定质量等级：

| 等级 | 分数 | 说明 |
|------|------|------|
| `S` | 9-10 | 改变格局：可能重塑 AI 领域的重要项目 |
| `A` | 7-8 | 直接有帮助：对开发者有实际价值 |
| `B` | 5-6 | 值得了解：有亮点但非必需 |
| `C` | 1-4 | 可略过：价值有限或过于小众 |

### 5. 验证评估

检查评估是否合理：
- 评分是否符合标准
- 等级是否与评分一致
- 是否有充分理由

### 6. 记录评估理由

为评估结果提供理由：
- 为什么给这个分数
- 有什么亮点
- 有什么不足

### 7. 输出结果

将评估结果添加到项目数据中。

## 注意事项

- 评分要严格，不随意给高分
- 评估要客观，基于实际数据
- 理由要充分，有说服力
- 不编造数据，所有信息来自实际分析

## 输出格式

```json
{
  "quality_level": "A",
  "quality_score": 8,
  "quality_reason": "项目有明确的应用场景，技术实现合理，社区活跃度高"
}
```
