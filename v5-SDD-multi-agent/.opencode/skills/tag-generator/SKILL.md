# 标签生成技能

## 使用场景

当需要为采集到的项目生成技术标签时使用此技能。

## 执行步骤

### 1. 读取项目信息

从原始数据中提取以下字段：
- 项目名称
- 项目描述
- 话题标签
- 技术栈

### 2. 分析技术方向

根据项目信息，确定主要技术方向：

| 方向 | 说明 |
|------|------|
| `llm` | 大语言模型 |
| `agent` | AI Agent |
| `rag` | 检索增强生成 |
| `multimodal` | 多模态 |
| `code-gen` | 代码生成 |
| `fine-tuning` | 微调 |
| `inference` | 推理 |
| `training` | 训练 |
| `dataset` | 数据集 |
| `tool` | 工具 |
| `framework` | 框架 |
| `application` | 应用 |

### 3. 提取相关标签

从项目信息中提取相关技术标签：
- 话题标签
- 技术栈
- 依赖库
- 应用领域

### 4. 生成标签组合

为项目生成标签组合：
- 1 个主要技术方向标签
- 2-4 个相关技术标签

### 5. 验证标签

检查标签是否合理：
- 标签是否准确
- 标签是否相关
- 标签数量是否合适

### 6. 去重处理

确保标签不重复：
- 同一标签不出现多次
- 相似标签合并

### 7. 输出结果

将标签添加到项目数据中。

## 注意事项

- 标签要准确，反映项目特点
- 标签要相关，与项目内容匹配
- 标签数量适中，不要太多或太少
- 不编造标签，所有标签来自实际分析

## 输出格式

```json
{
  "tech_direction": "llm",
  "tags": ["llm", "agent", "framework"]
}
```
